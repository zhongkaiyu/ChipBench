I would like you to implement a module named TopModule with the following
interface. All input and output ports are one bit unless otherwise
specified.

 - input  clk
 - input  rst_n
 - input  valid_in
 - input  data_in (8 bits)
 - output valid_out
 - output data_out (12 bits)

The module should implement a data width conversion circuit that converts
8-bit input data into 12-bit output data. The circuit uses valid-only
handshake mechanism for both input and output interfaces.

The data width conversion should work as follows:
- Input interface: Uses valid-only handshake mechanism
  - valid_in indicates the validity of input data_in
- Output interface: Uses valid-only handshake mechanism
  - valid_out indicates the validity of output data_out

Data conversion process:
- The module receives 8-bit input data_in when valid_in is high
- The module accumulates two 8-bit inputs to form a 12-bit output
- The first received 8-bit data should be placed in the high bits of data_out
- The second received 8-bit data should be placed in the low bits of data_out
- After receiving exactly 2 input data values, the module outputs data_out
  with valid_out asserted in the next clock cycle
- If only one data input is received, the module waits for the second input
  before producing any output

Clarification: Process inputs in groups of three 8-bit inputs, producing two 12-bit outputs per group (no bits are dropped). On the 2nd input of each group, output {first_byte, second_byte[7:4]} with valid_out high; on the 3rd input, output {second_byte[3:0], third_byte} with valid_out high.

rst_n is an active-low asynchronous reset: while it is low, valid_out and data_out are 0 and inputs are ignored; the first input after release starts a new group. valid_out is high for one cycle per output; data_out holds its value between outputs.
