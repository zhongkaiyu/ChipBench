I would like you to implement a module named TopModule with the following
interface. All input and output ports are one bit unless otherwise
specified.

 - input  clk
 - input  rst_n
 - input  wave_choice (2 bits)
 - output wave (5 bits)

The module should implement a signal generator that outputs different
waveforms based on the wave_choice input signal. The generator should
produce three different types of waveforms:

When wave_choice = 0: Generate a square wave signal
When wave_choice = 1: Generate a sawtooth wave signal  
When wave_choice = 2: Generate a triangular wave signal

The waveform generation should work as follows:
- The wave output should be a 5-bit signal that cycles through different
  values to create the desired waveform patterns. wave takes integer values
  0 to 20 (decimal); it never uses the full 5-bit 0-31 range.
- Each waveform should complete one full cycle and then repeat
- The square wave should alternate between high and low values: square = 20
  for 10 clocks, then 0 for 10 clocks (period 20 cycles, 50% duty).
- The sawtooth wave should increment from 0 to maximum value (20) and then
  reset: sawtooth counts 0->1->...->20, then wraps to 0.
- The triangular wave should increment from 0 to maximum (20), then decrement
  back to 0: triangle ramps 0->20 then 20->0, one step per clock.
