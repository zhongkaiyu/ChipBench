I would like you to implement a module named TopModule with the following
interface. All input and output ports are one bit unless otherwise
specified.

 - input  ALUOp   (2 bits)
 - input  Funct7  (7 bits)
 - input  Funct3  (3 bits)
 - output Operation (4 bits)

The module should implement an RISC-V ALU control decoder. It is purely
combinational and generates a 4-bit Operation code from ALUOp, Funct3,
and Funct7 to select the arithmetic/logic/shift/compare behavior in the ALU.

Operation is decoded as follows:

| ALUOp | Funct3 | Funct7 | Operation |
|-------|--------|--------|-----------|
| 00 | any | any | 0010 |
| 01 | 000, 010 or 011 | any | 1000 |
| 01 | 001 | any | 1001 |
| 01 | 100 | any | 1100 |
| 01 | 101 | any | 1101 |
| 01 | 110 | any | 1110 |
| 01 | 111 | any | 1111 |
| 10 | 000 | 0100000 | 0110 |
| 10 | 000 | any other value | 0010 |
| 10 | 001 | any | 0100 |
| 10 | 010 | any | 1100 |
| 10 | 011 | any | 1110 |
| 10 | 100 | any | 0011 |
| 10 | 101 | 0000000 | 0101 |
| 10 | 101 | 0100000 | 0111 |
| 10 | 101 | any other value | 0000 |
| 10 | 110 | any | 0001 |
| 10 | 111 | any | 0000 |
| 11 | any | any | 1010 |
